1.) Input

This App uses text text and images within different view components. This will render a profile for card for a user. Our component get out styles from a StyleSheet created at the bottom of the App.js

2.)Process

We import the necessary react modules for text, view and image and style sheet. We create an App class component that will render the application. We make one main view container that is filled with a view for the image and 3 more views for the text components. These components take their styles form the StyleSheet for the different container and the image location.

3.) Output

We render a blue card container with an image conainer that is made into a circle with is border radius style. Then we see the first text view with bold text, colored white and with a shadow opacity style. We then have a text for the occupation with a bottom border and finally, the card description text that is is style with italics. The different components for the card are inside the card component which is postioned inside the main container.
